# EBLIN KIM — GitHub Pages starter

## Files
- index.html — homepage
- style.css — layout/design
- images/ — replace placeholders with your actual artwork images

## Replace images
Put these files into `images/`:
- hero.jpg
- work-01.jpg
- work-02.jpg
- work-03.jpg
- artist.jpg

Recommended:
- hero.jpg: large representative artwork
- work-01~03.jpg: selected works
- artist.jpg: optional artist portrait

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, and the `images` folder.
3. Repository Settings → Pages → Deploy from a branch → `main` / `root`.
4. Open the generated `github.io` URL.
5. Later, add your custom domain under Settings → Pages → Custom domain.

The site is plain HTML/CSS/JS and needs no build system.
